# RealmShards

Unity 6 (6000.5.6f1) URP 2D local co-op action roguelite — Steam Deck + Windows desktop.

## Play

See **[Assets/Game/Docs/PLAY_NOW.md](Assets/Game/Docs/PLAY_NOW.md)** and **[Assets/Game/Docs/INPUT.md](Assets/Game/Docs/INPUT.md)**.

1. Run setup menus: Player Content, CityRun Stage 2, Items Content, Magic Schools.
2. Open `Assets/Game/Scenes/Bootstrap.unity` → Play.
3. Hub: Space/A join (mixed KBM + pads) → loadout → Start Run.
